A simple, lightweight, password manager, for all.
Compatible with Windows, Android, (Linux TBA)
Requirements For Building Yourself:
(Node.js, NPM, Electron) (https://www.electronjs.org/docs/latest/tutorial/tutorial-first-app)

Setup files can be found in the releases tab.

What this manager includes:
CSV Importing, Exporting to TXT, Encryption, Search bar (for if you have hundreds of passwords like me), Theme Selection, Pin Codes (With 5 Minute Timeout)
(Background theme is animated // If performance issues occur, setting to implement static background will be made)

DEFAULT PIN IS: 1111 // Changeable in settings after first setup.
